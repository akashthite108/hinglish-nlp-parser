An enterprise-grade, zero-lag Natural Language Processing (NLP) and automation engine designed to parse \*\*code-mixed regional text (English, Hindi/Hinglish, and Marathi/Mar-Hinglish)\*\* across D2C Customer Support and B2B Procurement domains.



\---



\## ✨ Key Enterprise Features



1\. \*\*Tri-Lingual Code-Mixed Intent Classification:\*\* Natively parses casual, unstructured phrases combining English, Devanagari/Latin Hindi, and Marathi idioms into clean business intents (e.g., \*Urgent Support\*, \*Price Negotiation\*, \*Procurement RFQ\*, \*Technical Bugs\*).

2\. \*\*🎙️ WhatsApp / Telegram Voice Note Simulator:\*\* Simulates voice note transcriptions from field managers and buyers on construction sites or retail channels.

3\. \*\*🏷️ Intelligent Entity \& Rate Extractor:\*\* Regex-powered structured data parser that extracts specific \*\*Items\*\*, \*\*Quantities\*\*, and \*\*Target Rates/Prices\*\* into clean tabular formats.

4\. \*\*🌡️ Supplier Risk \& Frustration Scorecard:\*\* Calculates emotional urgency and sentiment indexes in real-time, plotting cumulative vendor risk trends over session history.

5\. \*\*🔗 Enterprise ERP Webhook Visualizer:\*\* Generates live, outgoing JSON API payloads instantly formatted for backend integration with SAP, Odoo, or custom procurement ledgers.



\---



\## 🛠️ Tech Stack

\* \*\*Frontend \& UI:\*\* Streamlit

\* \*\*Machine Learning \& NLP:\*\* Scikit-Learn (TF-IDF Vectorizer + Logistic Regression pipeline)

\* \*\*Data Processing \& Analytics:\*\* Pandas, Regular Expressions (Regex)

\* \*\*Language Support:\*\* English, Hindi (Hinglish), Marathi (Mar-Hinglish)
